## Running a Project

Clone the repository:

```bash
git clone https://github.com/shalimkeith/100-days-of-code-python
```

Move into a project folder:

```bash
cd Day32
```

Run the project:

```bash
python main.py
```

If required, install dependencies:

```bash
pip install -r requirements.txt
```
